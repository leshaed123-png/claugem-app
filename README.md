# ✦ Claugem

Самообучающийся ИИ-агент для Mac: пишет код и интерфейсы, правит файлы, запускает команды,
запоминает факты о тебе и **сам создаёт себе навыки** после решения задач.

## Запуск (на Mac)

```bash
npm install
npm run dev        # разработка
npm start          # собрать и запустить
npm run dist       # собрать .dmg
```

Нужен Node.js 18+. При первом запуске открой ⚙ и выбери провайдера.

## Провайдеры

| Провайдер | Цена | Лимиты |
|---|---|---|
| Google Gemini | бесплатный тариф | есть (запросы/минуту и в день) |
| Groq | бесплатный тариф | есть |
| OpenRouter `:free` модели | бесплатно | есть |
| **Ollama (локально)** | бесплатно | **без лимитов**, качество зависит от твоего железа |
| Claude API | платно | по тарифу |

Все работают через единый OpenAI-совместимый интерфейс — добавить нового провайдера = одна строка в `electron/store.js`.
При ошибке лимита (429) агент сам ждёт и повторяет запрос.

## Как он учится

- `memory.md` — факты о тебе и проектах (`save_memory`)
- `skills/*.md` — рецепты решения задач (`create_skill`), подгружаются в промпт

Хранится в `~/Library/Application Support/Claugem/`. Это обучение на уровне знаний и инструкций,
а не дообучение весов модели.

## Безопасность

Агент работает только внутри выбранной рабочей папки; команды по умолчанию выполняются после твоего подтверждения.
