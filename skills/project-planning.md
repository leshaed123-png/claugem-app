---
name: project-planning
description: Планирование большой задачи перед кодом
---

1. Сформулируй цель одним предложением и критерии готовности.
2. Разбей на шаги по 15-30 минут, у каждого проверяемый результат.
3. Сначала рабочий минимальный вертикальный срез (от UI до данных), потом расширение.
4. После каждого шага запускай проект; не копи ошибки.
5. В конце: README с запуском, список известных ограничений.
