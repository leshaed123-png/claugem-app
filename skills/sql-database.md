1. Таблицы в 3НФ: первичный ключ, внешние ключи, NOT NULL, UNIQUE, индексы на поля поиска/JOIN.
2. Миграции версионировать файлами; не править применённые.
3. Запросы параметризованные (защита от SQL-инъекций), без SELECT * в коде.
4. Медленный запрос: `EXPLAIN ANALYZE`, добавь индекс, проверь план.
5. Транзакции для связанных изменений; деньги — integer в копейках или numeric.
6. Для приложений на одном устройстве хватит SQLite.
