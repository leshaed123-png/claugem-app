description: Простая 2D-игра на HTML5 Canvas
---

1. Цикл requestAnimationFrame; delta time для скорости, не привязывайся к FPS.
2. Состояние игры в одном объекте; update(dt) отдельно от draw().
3. Ввод: keydown/keyup в Set нажатых клавиш.
4. Столкновения AABB: прямоугольники пересекаются по обеим осям.
5. Звуки/спрайты не нужны для старта — рисуй фигурами; добавь счёт, паузу, рестарт.
