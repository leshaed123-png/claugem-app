description: Алгоритмы и структуры данных
---

1. Уточни ограничения (размер входа) → выбери сложность: n≤10^5 → O(n log n).
2. Типовые приёмы: хеш-таблица (поиск за O(1)), два указателя, скользящее окно, бинарный поиск по ответу, BFS/DFS, DP (состояние + переход), куча для top-k.
3. Сначала корректное простое решение, потом оптимизация.
4. Проверь на крайних случаях: пусто, один элемент, дубликаты, отрицательные.
