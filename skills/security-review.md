---
name: security-review
description: Ревью безопасности кода
---

1. Ввод пользователя: валидация, экранирование вывода (XSS), параметризованные запросы (SQLi).
2. Секреты: не в коде и не в git; проверь `git log -p | grep -i key`; ротируй утёкшие.
3. Аутентификация: хеш паролей argon2/bcrypt, ограничение попыток, безопасные cookie (HttpOnly, Secure, SameSite).
4. Файлы/пути: запрети `..`, проверь что путь внутри разрешённой папки.
5. Выполнение команд: никогда не подставляй пользовательский ввод в shell-строку.
6. Зависимости: `npm audit` / `pip-audit`.
