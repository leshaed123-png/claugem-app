name: css-design
description: Дизайн-система и красивый CSS
---

1. Токены: цвета (фон, поверхность, акцент, текст, приглушённый), радиусы, тени, отступы 4/8/12/16/24/32.
2. Контраст текста не ниже 4.5:1; акцентный цвет один основной + один вспомогательный.
3. Глубина: слои поверхностей, тонкая граница, backdrop-filter:blur для «стекла».
4. Иерархия: размер и вес шрифта, а не только цвет; много «воздуха».
5. Микровзаимодействия: hover-подъём translateY(-1px), плавный focus-ring.
6. Адаптив: clamp() для размеров, grid с auto-fit/minmax.
